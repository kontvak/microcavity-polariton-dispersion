# План разбора рисунков

Порядок: **12 → 15 → 9**.

Номера в плане соответствуют префиксам файлов `figures_v2`; в PDF нумерация автоматическая.

- [x] **Рисунок 12.** Пересчитать по спектрам TMM при фиксированном тангенциальном $E_x$ и сборе обеих выходных поляризаций. Доли TE/TM нормированы по входной мощности. Сверху — все спектральные максимумы LP/UP, включая разрешённый TE/TM-дублет; чёрный и зелёный срезы — чистые TM и TE. Снизу — сдвиг наиболее сильного максимума относительно среднего чистых TE/TM-максимумов, с разрывами при переключении между пиками. Это положения максимумов прохождения. Масштабы одинаковы внутри ряда. Проверены формулы Френеля, баланс мощности, точное решение DBR, чистые срезы, симметрия и сходимость энергетической сетки. Ноутбук выполнен полностью; русский и английский текст обновлён. Предыдущая проекция удалена. Устранены искусственные щели верхней UP-панели на границе одного/двух максимумов; сетка сгущена до 161×161. Дополнительная карта спектров проверяет непрерывность прохождения и появление второго UP-максимума.
- [x] **Исходный рисунок 8 (`08_RTA_fixed_angles.png`).** Исключён из русского и английского отчётов вместе с его обсуждением по решению пользователя.
- [x] **Рисунок 15.** Проверены определения энергий и разностей при одинаковом $k_\parallel$. Для отчёта оставлен один график разностей модели и минимумов отражения относительно действительных частей TMM-полюсов; верхняя дисперсионная и нижняя угловая панели убраны. Русское и английское пояснения согласованы с новым рисунком.
- [x] **Рисунок 9.** Проверены четыре периода интенсивности, фазы отражения DBR и пучности на границах полости; амплитуда на границах QW составляет около 0.997 от максимума. Пояснены выбор центральной пучности z₀, разные координаты панелей и перенастройка длины полости. Формула оценки записана через Δz_QW с прямым обозначением I; уточнено различие оценки по полю и расщепления комплексных полюсов при потерях. Краткие пояснения добавлены в русский и английский отчёты.
