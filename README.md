# Dispersion Curve

A numerical model of exciton-photon polaritons in a planar DBR microcavity.

- `microcavity_polaritons.ipynb` — calculations, figures, and numerical checks;
- `microcavity.py` — numerical functions;
- `figures/` — plots generated by the notebook;
- `data/` — saved numerical data for the comparison and diagnostic plots;
- `latex/report.tex` and `latex/report.pdf` — Russian report;
- `latex/report_en.tex` and `latex/report_en.pdf` — English report;
- `test_polarization.py` — physical checks for polarized transmission.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook microcavity_polaritons.ipynb
```

## Reproduce the calculations

Run from the repository root. The calculation can take several minutes.

```bash
MPLBACKEND=Agg jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=3600 microcavity_polaritons.ipynb
```

The notebook writes `figures/` and `data/`. The reports contain 14 figures.
File prefixes retain the calculation numbering: `08_RTA_fixed_angles.png`
and `12_UP_spectral_diagnostic.png` are diagnostic plots outside the reports.
PDF figure numbering is automatic.

Figure 12 computes transmission maxima for a fixed tangential electric field
along x, collecting both output polarizations. The upper surfaces retain all
detected maxima; the lower surfaces show the strongest-peak shift relative
to the mean pure TE/TM peak energy. The separate UP diagnostic displays the
underlying continuous transmission spectra.

## Build the reports

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error -output-directory=latex latex/report.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error -output-directory=latex latex/report_en.tex
```
